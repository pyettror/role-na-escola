# Rolê na Escola
Primeira versão visual do site de cobertura de eventos escolares.

- `index.html`: página inicial e arquivo de eventos.
- `styles.css`: identidade visual azul e branca, adaptada para celular.
- `script.js`: estrutura inicial do filtro por ano.

**Atenção:** esta versão ainda não tem painel administrativo seguro, banco de dados, autenticação nem upload real de fotos e vídeos. Essas funções serão adicionadas nas próximas etapas. Nunca coloque senhas ou chaves secretas no repositório.
